# Power BI Dashboard

## Smart Fraud Detection Dashboard

The Power BI dashboard provides an interactive analytical interface
for monitoring fraudulent transaction activity from the Gold layer of
the Databricks pipeline.

## Dashboard Components

- Executive KPIs
- Fraud transactions over time
- Fraud by type
- International vs domestic fraud
- Daily fraud rate
- Top accounts by fraud amount
- Transaction-level investigation
